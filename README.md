# Slide Local

Built with PLaMo · Powered by Ollama

Apple Silicon Mac向けの、SwiftUI製PowerPoint翻訳・資料チャットアプリです。資料の取り込み、翻訳、編集可能なPPTXの保存、スライドのプレビュー、資料への質問をローカルで行います。画面は日本語です。

**導入する人と、そのAIエージェントは最初に [INSTALL.md](INSTALL.md) を読んでください。** 必要なソフト、モデル、ローカル専用設定を確認してからビルド・インストールする順序になっています。

## できること

- PPTXの複数選択・ドラッグ＆ドロップと、1資料ずつ処理する永続キュー。
- PLaMoによる翻訳、原文と訳文の比較、訳文の手動編集、PPTX保存・一括保存。
- Ollamaに保存した会話モデルで、資料全体や現在のスライドについて質問。
- LibreOfficeとPDFKitによるスライドプレビュー。
- 段落単位の翻訳キャッシュ、処理の再開。翻訳モデルをメモリに保持して再利用。

SwiftUIの画面とSwiftエンジンを1つのアプリにまとめています。実行にPython、Webブラウザ、独自のWebサーバーは必要ありません。Ollamaは別プロセスのローカル推論サービスとして利用します。

Ollamaは **CLI版＋ログイン時自動起動サービス** を標準とし、GUIアプリやClaude Code／Codexとの連携は不要です。Slide LocalはOllamaの起動・停止を行いません。既存GUI版を利用する場合は手動で起動してください。導入・移行は [INSTALL.md](INSTALL.md) を参照してください。

## 必要な環境

Apple Silicon、macOS 14以降、Xcode Command Line Tools、Ollama、ローカルモデルが必要です。プレビューにはLibreOfficeが必要です。標準構成は翻訳に `plamo-translate:0.8b`、チャットに `qwen3.5:4b` を使用します。メモリ16GB以上を推奨します。これは性能上の目安で、モデルと資料によって必要量は変わります。

依存ソフトとモデルの初回取得にはインターネット接続が必要です。準備後の翻訳・チャット・プレビューはオフラインで利用できます。

## 使い方

1. 「PowerPointを開く…」またはドロップでPPTXを取り込みます。読み込み・翻訳では元ファイルを変更しません。
2. 原文の言語・翻訳する言語を選び、「この資料を翻訳する」を押します。翻訳モデル・発表者ノート・保存時の文字サイズ調整は詳細設定にあります。
3. 「原文と訳文を確認・修正」で内容を確認し、必要なら訳文を編集します。変更はボタンのほか、資料切り替え・書き出し時にもアプリ内へ保存します。
4. 「翻訳したPowerPointを保存…」で保存先を選びます。**アプリ内への訳文保存とPowerPointファイルの保存は別操作**です。保存先に既存ファイルや元ファイルを選ぶと上書きになるため、確認してください。
5. 「この資料について質問」で質問用モデルと参照範囲を選び、質問します。送信は⌘Returnです。参照は原文・保存済み訳文の関連抜粋で、全ページを漏れなく扱うものではありません。画像内の文字・ノートは参照しません。停止・失敗した質問と未完了回答は履歴に保存しません。
6. 「スライド画像を確認」に切り替え、原本／翻訳後を選んで「プレビューを作成・更新」を押します。LibreOfficeが必要です。画像が古いときは説明が表示されるので更新してください。

### 複数資料と翻訳の進行状況

内部では永続キューを維持し、予約の追加順に1件ずつ処理します。他資料が先に予約されている場合は順番待ちになります。「翻訳の進行状況」で一覧、停止、予約取消、再試行、一括保存を操作できます。

複数ファイルを取り込んだ成功分は、進行状況の「取り込んだ資料をまとめて翻訳」から共通設定で予約できます。未予約の対象一覧はその起動中だけのものです。登録した予約は次回起動にも残ります。単体で取り込んだ資料には、重複する一括翻訳操作を表示しません。

「次の資料から一時停止」は処理中の資料が終わってから反映されます。一時停止中は「翻訳を予約する」と表示し、再開するまでは始まりません。資料ごとの停止は現在のリクエスト完了まで待つ場合があり、完了した訳文は保持します。

言語・モデルを変更すると、対象外のノートを含む現在の訳文と手修正が消える場合があるため、実行前に対象・設定・影響を確認します。確認した内容が変わった予約や安全に復元できない旧予約は「確認が必要」として保留し、後続を続けます。履歴の再試行には、その履歴に保存された設定を使用します。同じ設定の実行では完了済み文章を再翻訳しません。

一括保存は、資料ごとの**最新の翻訳履歴が完了している資料**が対象です。手編集で修復しても履歴が要確認なら単体で保存してください。一括保存は画面の未反映設定を使わず、保存済み設定で書き出し、同名ファイルには連番を付けます。

ウィンドウを閉じてもアプリ実行中は処理を続け、⌘Qの後は次の起動時に未完了の処理を復元します。明示的に停止・取消した資料は自動で再開せず、一時停止状態と確認待ちも維持します。Macのスリープ中は進みません。

## ローカルデータと通信

資料、翻訳、会話、SQLiteキャッシュ、キュー、プレビューは `~/Library/Application Support/Slide Local/` に保存します。このリポジトリには利用者の資料や会話を含めません。

アプリの推論接続先は `127.0.0.1:11434` に固定しています。プロキシ、リダイレクト、HTTPキャッシュを使わず、各翻訳リクエストとチャット開始前に、Ollamaのクラウド無効状態とモデルのローカル保存を再確認します。確認できなければ本文を送信せず停止します。アプリには外部API連携、テレメトリ、モデル自動取得機能はありません。

プレビューは外部参照を除いた専用コピーを作り、通信・読み書き先・子プロセス起動を制限したLibreOfficeで描画します。制限の適用に失敗した場合は、制限なしで再実行しません。元のPPTXと保存したPPTXの外部リンクは保持します。他アプリで開く際のリンク取得は、そのアプリの設定に依存します。

Ollama・OS・他アプリの更新通信や、バックアップ、同期、AIエージェントへの資料送信まで遮断するものではありません。保管先がバックアップ・同期対象かは利用者の環境で確認してください。

## 対応範囲

通常のテキスト、グループ、表、グラフ、SmartArt、任意のノートのテキストを扱い、画像・図形・スライド順などの構造を保ちます。画像に焼き込まれた文字、数式、動画、マスター／レイアウトの文字は翻訳しません。複数書式の強調位置は近似します。旧形式PPTと暗号化PPTXには対応しません。

ファイル容量・展開容量・メンバー数にアプリ独自の固定上限はありません。ZIP64にも対応しますが、空きディスク、メモリ、個々のXMLやモデルのコンテキスト長による制約はあります。LibreOfficeの表示はPowerPointと異なることがあります。翻訳とAI回答は利用者が確認してください。

## 開発

```sh
./build-native.command --stage
```

`.cache/native/Slide Local.app` に検証用アプリを作成し、ローカルのアドホック署名を付けます。`--stage` なしではリポジトリ直下にもアプリを作成します。ビルド中にパッケージやモデルをダウンロードしません。

主要なソースは `NativeApp.swift`（画面・操作制御）、`NativeWorkflowViews.swift`（翻訳フロー・進行状況）、`NativeTranslationPolicy.swift`（状態判定・翻訳許可）、`NativeEngine.swift`（処理・キュー）、`NativeOllama.swift`（推論）、`NativeStore.swift`（保存）、`NativeZIP.swift` / `NativePPTX.swift`（PPTX）、`NativePreviewPolicy.swift`（描画制限）です。

テスト方法は [tests/README.md](tests/README.md) を参照してください。変更を公開するときも、架空の資料だけを使い、資料本文・会話・ローカルパス・認証情報・生成ログを含めないよう確認してください。
